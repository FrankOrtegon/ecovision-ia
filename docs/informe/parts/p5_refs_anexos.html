Anexo B

Reproducibilidad

Todo el análisis puede reproducirse desde el repositorio (commit [[commit]], generado el [[fecha_larga]]). Los pasos, desde la raíz del proyecto con Python 3.12, son:

  • Entorno: crear el entorno virtual e instalar ml/evaluation y backend.
  • Datos: ejecutar en orden ml/scripts/01_download_dataset.py, 02_explore_dataset.py, 03_split_dataset.py y 04_prepare_roboflow_upload.py (semilla 42).
  • Evaluación: 05_run_evaluation.py (validación con --split val; prueba solo con --final) y 06_analyze_results.py.
  • Figuras e informe: docs/informe/make_figures.py y docs/informe/build_informe.py, que leen los resultados guardados y generan este documento.

El entrenamiento en Roboflow no es reproducible de forma exacta con la información que expone la plataforma (véase Limitaciones); sí lo son la preparación de datos, la evaluación y la aplicación.

Anexo C

Incidencias y Decisiones del Proceso

  • Duplicados con etiquetas contradictorias. Se detectaron durante la exploración y se excluyeron antes de particionar.
  • Visibilidad del conjunto de prueba. Roboflow muestra por defecto sus evaluaciones automáticas sobre el conjunto de prueba. Se vieron en pantalla para ambos modelos, no se usaron para decidir y la selección se hizo con la validación. El script de evaluación exige una bandera explícita para tocar la prueba y registra cada uso.
  • Exposición de una credencial. Una clave de API se compartió por error en una conversación y quedó escrita en un archivo de plantilla versionado de un repositorio público. La clave se revocó, se comprobó que la anterior devolvía un error 401 y que la nueva funcionaba, y desde entonces se revisa el contenido de los archivos antes de publicar.
  • Cambio de cliente HTTP. El diseño inicial usaba el SDK de Roboflow; se pasó a llamadas HTTP directas para fijar el tiempo de espera por solicitud y paralelizar. La llamada sigue aislada en un único módulo.
